Title - AI Interview Tracker & Mock Interview Platform

A full-stack AI-powered interview preparation platform that helps users track interview applications, analyze performance trends, and practice mock interviews using LLM-based feedback and scoring.

Features:-
- JWT authentication
- AI mock interviews
- Resume ongoing AI interview sessions
- Interview analytics dashboard
- WebSocket real-time updates
- Search & filtering
- Pagination
- User-specific interview management

Tech-Stack
Frontend:
- React
- Tailwind css
Backend:
- Node.js
- Express.js
- WebSockets
Database:
- MySQL
AI:
- Groq LLM
